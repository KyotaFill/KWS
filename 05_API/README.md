# API KWS

OpenAPI được sinh từ `create_app()` hiện tại: **109 đường dẫn, 139 thao tác HTTP**.

- [OpenAPI](openapi_runtime.json)
- [Danh sách thao tác](contract_inventory.json)

Tài liệu trực tiếp: `/api/v1/docs`. Giao thức dùng header `X-KWS-API-Protocol` và `X-KWS-Recovery-Protocol`. Các API phân hệ đã bỏ không được đăng ký. API kỳ kho được giữ cho việc thiết lập/duy trì kỳ có kiểm quyền.
